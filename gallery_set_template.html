Auto-extracted, not ground truth. Values come straight from each paper's own results table via an LLM read — protocols, backbones, and splits vary even within one dataset+metric pair. Check the setting column, and the paper itself, before citing across rows. Dataset/metric names are normalized for exact-match spelling variants only (e.g. “Market-1501” / “Market1501”); genuinely different protocols are kept separate on purpose.
