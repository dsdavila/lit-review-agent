A literature browser for — person/object re-identification papers pulled from CVPR, ICCV, ECCV, WACV, and BMVC (2022–2026). Filter to a task, benchmark, or year; pick a dataset and metric to rank papers by what they reported. Every card expands to the paper's full critical summary.

Auto-extracted, not ground truth. Benchmark numbers come straight from each paper's own results table via an LLM read — protocols, backbones, and splits vary even within one dataset+metric pair, so ranking by value is a starting point, not a citable leaderboard. Dataset/metric names are normalized for exact-match spelling variants only (e.g. “Market-1501” / “Market1501”); genuinely different protocols are kept separate on purpose.

Built from a metadata-first scrape of CVPR/ICCV/ECCV/WACV/BMVC 2022–2026 proceedings, filtered to person/object re-identification relevance, then read paper-by-paper for contributions, deficiencies, and headline results. One source PDF was excluded as corrupted. “Other CV Research” papers were pulled in by broader search terms (tracking, segmentation, wildlife monitoring, etc.) rather than being re-identification work themselves.
